# :design:riso

- Public API and usage: [README.md](README.md). Keep it in sync when the public API changes.
- Rules and platform source sets: [design-system.md](../../docs/architecture/design-system.md).
- Material stays internal: `material3` is an `implementation` dependency. Don't expose Material types in public signatures or change it to `api`.
- Theme values are read through `RisoTheme.*`; new `Local*` composition locals are `internal`.
- Anything that draws with the print effect must degrade when `effectsEnabled = false` (flat colors, no shaders).
- Shared Skia code goes in `skikoMain`; only put code in `androidMain`, `bakedPaperMain`, `metalBakeMain` or `inlinePaperMain` when it is platform-specific.
- The shader effect differs per platform, so a visual change needs checking on more than one target.
- `docs/*.webp` are generated by `:design:risoRecorder` (`./gradlew :design:risoRecorder:run`), not edited by hand. `:design:risoDemo` is an Android app hosting `RisoPrintDemo`.
