# SideQuests

A Kotlin Multiplatform repo holding a collection of personal apps that share one architecture, one design system (Riso) and a set of reusable libraries.

- Architecture docs start at [docs/architecture/README.md](docs/architecture/README.md).
- Before adding a module, read [modules.md](docs/architecture/modules.md).
- Don't follow patterns used in /tools
- Behavior specs live in [openspec/specs](openspec/specs/). Non-trivial behavior changes go through an OpenSpec change (`/opsx:propose`, `/opsx:apply`, `/opsx:archive`).
